💡 How Matrix Multiplication Works

For two matrices to be multiplied (A × B = C), the number of columns in A must equal the number of rows in B. If A is m × k and B is k × n, then C is m × n.

📐 The Formula

Each element C[i][j] is computed by taking the dot product of Row i of Matrix A and Column j of Matrix B:

C[i][j] = ∑k ( A[i][k] × B[k][j] )
